# Kaggle Dataset Notes

## 1. Women's E-Commerce Clothing Reviews — USE
Kaggle: https://www.kaggle.com/datasets/nicapotato/womens-ecommerce-clothing-reviews
Verified dataset card: 23,486 rows, 10 feature variables, anonymised real commercial data, CC0.

Best use: contextual qualitative/quantitative evidence for clothing satisfaction and reasons such as fit/quality/comfort/style.
Not valid for: India-wide behaviour, textile waste volumes, disposal rates.

## 2. Clothing Fit Data — USE SELECTIVELY
Kaggle: https://www.kaggle.com/datasets/pypiahmad/clothing-fit-data
Original dataset information: https://mcauleylab.ucsd.edu/public_datasets/data/datasets.html
ModCloth: 47,958 users, 1,378 items, 82,790 transactions.
RentTheRunway: 105,508 users, 5,850 items, 192,544 transactions.

Best use: small optional explainer when the visitor chooses “It doesn't fit”.
Not valid for: disposal behaviour or India-wide claims.

## 3. Fast Fashion Eco-Data — OPTIONAL / ILLUSTRATIVE
Kaggle: https://www.kaggle.com/datasets/thedevastator/fast-fashion-eco-data
Underlying Zenodo record: https://zenodo.org/records/4261101
Scope: 277 items in the Spanish Zara catalogue, retrieved 2020-11-07, with item and composition dimensions.

Best use: illustrate structured garment composition data.
Not valid for: representative India material composition or direct recyclability claims.

## Download note
The pack does not pretend to include Kaggle source files that were not actually downloaded. Add the original files only through Kaggle's permitted download mechanism, then clean them according to `data_cleaning_plan.md` and the schemas in `data_dictionary.md`.
