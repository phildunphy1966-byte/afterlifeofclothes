# The Afterlife of Clothes — Google AI Studio Build Pack
Build a responsive interactive data-storytelling website following one unwanted T-shirt from a user's wardrobe into India's post-consumer textile-waste system.

Use the included files as the product brief. Never invent missing survey data. Keep sources visible and make interactions meaningful, accessible and mobile-friendly.

Files: master_prompt.md, information_architecture.md, story_and_content.md, interaction_spec.md, visual_design_system.md, data.md, components.md, testing_and_accessibility.md, sources.md.

## Dataset update
This version adds a research-safe dataset architecture:
- `dataset_strategy.md`
- `data_dictionary.md`
- `data_cleaning_plan.md`
- `kaggle_dataset_notes.md`
- `data/national_textile_flow.csv`
- `data/survey_template.csv`
- `data/consumer_reviews_schema.csv`
- `data/clothing_fit_schema.csv`
- `data/garment_composition_schema.csv`

Only the national textile-flow CSV contains populated research values. Kaggle-derived CSV files are intentionally schemas until the original datasets are supplied/downloaded and cleaned. This prevents fabricated data from entering the website.
