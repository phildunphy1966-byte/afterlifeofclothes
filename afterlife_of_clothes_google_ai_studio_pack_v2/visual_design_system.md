# Visual Design System
Direction: **fashion editorial + garment care labels + tactile textile cues + rigorous data visualisation**.

## Colours
Fabric cream `#F2EFE8`; Charcoal `#191919`; Muted text `#6F6C66`; Border `#D4D0C7`; Reuse `#65785F`; Recycle `#637A83`; Downcycle `#9A7A52`; Disposal `#A64B32`.

## Type
Display: Instrument Serif or similar open-source editorial serif.
Body/UI/Data: Inter or Manrope.
Hero: clamp(3.5rem, 9vw, 9rem). Section: clamp(2rem, 5vw, 5rem). Body: 1rem–1.125rem.

## Layout
12-column desktop grid, max ~1440px, generous whitespace. Alternate full-bleed visual sections with focused editorial text.

## Graphic language
Garment-label frames, stitch/dashed rules, continuous thread progress line, garment silhouettes, care-label-style source tags, subtle textile texture.

## Charts
Direct labels, visible units and sources. No 3D. Donut/stack for 58/42; Sankey for flow; pictogram for 55/45; bars/dots for survey.

## Motion
Restrained editorial motion. UI 250–700ms; narrative transitions up to ~1200ms. No bouncy motion. Support reduced motion.

## Responsive
Desktop rich split layouts; tablet simplified flows; mobile single-column and tap-based interactions.
